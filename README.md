# Stefan Marquart

I build tools that make public data useful and claims traceable to their sources.

## Selected work

- **[OPAL — Open Procurement Access Layer](https://github.com/smarqart-hash/opal-tenders)** · Open-source alpha for European tender research. A source atlas maps 98 routes; six search integrations provide working starting points for your own workflows.
- **[Rateo](https://rateo.berlin)** · A live project, developed with Simon Boffen, for exploring Berlin borough assembly records with links to the official originals. [Data, coverage and MCP documentation](https://rateo.berlin/daten).
- **[TED procurement data quality](https://github.com/smarqart-hash/ted-procurement-data-quality)** · Reproducible analysis of placeholder contract values in European procurement data and their effects on integrity indicators.

## Reference projects

- **[Inspectable Agent Pipelines](https://github.com/smarqart-hash/inspectable-agent-pipelines)** · A TypeScript reference for validated handoffs, run logs and review gates.
- **[Evidence-Bounded Answer Lab](https://github.com/smarqart-hash/evidence-bounded-answer-lab)** · A synthetic demo of answers that cite evidence, mark partial coverage or abstain.
- **[Structured AI Research Workflows](https://github.com/smarqart-hash/structured-ai-research-workflows)** · A documented workflow for tracking sources, claims, uncertainty and human decisions.
